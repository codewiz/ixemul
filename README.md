# ixemul 80.x
Ixemul 80.x for AmigaOS m68k – development, bug fixes, and compatibility improvements.

Ixemul is a Unix/POSIX compatibility and C runtime library for AmigaOS on Motorola 68k systems. It provides Unix-like system calls and library functions used by software ported to AmigaOS.

The 80.x series focuses on improving stability, correctness, and compatibility while maintaining support for existing ixemul-based applications.

**Latest stable release:** 80.2  
**In development:** 80.3

See `NEWS` and `ChangeLog` for details about changes and fixes.
